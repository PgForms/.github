---

pgforms turns typed entity definitions into real PostgreSQL tables, a data API,
permissions, workflows and a FluentUI interface. The genuinely hard parts stay
as ordinary TypeScript.

The platform is in private development. This organisation will host the
framework, official modules and the Cloud tooling as they become public.
